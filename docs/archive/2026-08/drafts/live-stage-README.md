Reference documents for the lanes that build the stage. They are drafts, not published
contracts: nothing mirrors them and no public surface links here.

- live-stage-mock.html: the owner-approved motion mock, version 6 (2026-09-05). Open it in a
  browser; it plays a fake day. It is the reference for feel and behaviour, not for code.
- live-stage-mock-brief.md: the original brief the mock was built from (the owner rulings).
- live-stage-round-four-defects.md: the four defects the owner rejected in version 3 and how
  version 4 fixed them (rotation, overlap, bubble anchoring, dashing through walls).
- live-stage-round-five-set-pieces.md: the owner's wording for using, making, and founding.
- live-stage-round-six-long-notes.md: long notes scroll inside the bubble.
- live-stage-borrow-list.md: behaviours worth borrowing from the Frontier Valley replay page,
  ideas only. No line of their code, CSS, class name, or file naming is reused; no licence
  permits it.
- live-stage-blueprint.md: the fifteen-step build plan and the decision row text.
